# 小岩

女儿陪母亲找一张旧照片里的陌生女人。查到最后才发现，那不是失散的亲戚，而是母亲成为“妈妈”以前的自己。别人叫她洪梅，但是小岩是她最初的名字。

母亲一直念叨的小岩的名字 

72岁的洪梅最近发生的事情记不牢，却对一张自己七八岁时期的照片产生很强的熟悉感。



# **1\. 一句话**

72 岁的洪梅有早期认知障碍。女儿张知夏回家办完父亲丧事、收拾老屋时，翻出一张没写名字的年轻女人照片。母亲说：“我要找到她。她不叫洪梅。”两人一起做饭、听磁带、认亲戚，去找这个人。

找到最后，照片里的女人就是她自己。



# **2\. 两名玩家分别在做什么**

2D 横向、点击交互的**双人非对称**叙事游戏。两个人坐在一起玩，屏幕信息不同，必须说话才能往下走。

原则就一句：**母亲玩益智关，女儿玩调查本。女儿不能代点完成，只能给线索、记发现、把故事往前推。**

画面几乎是灰的。不是“治好了就变彩色”。一件东西被两个人一起理解了，才慢慢有颜色。母亲此刻自己选的颜色，马上出现。过后她可能又忘，颜色留下。

# **两人怎么坐在一起玩**

最省事、也最像照料现场的做法：**并排坐，两块屏。** 母亲一块大平板（或电视\+简易手柄/点击），女儿一块手机或另一块平板。必须开口说话，系统不自动同步答案。

**一局的固定节奏（四个游戏都套这个）：**

1. 女儿翻到一件东西，读一句很短的话（“这页没标题。”“背面写了小石。”），把任务推到母亲屏上。

2. 母亲自己做益智。卡住了，可以按「帮我看看」——这是她主动要提示，不是女儿抢。

3. 女儿从调查本里选提示层级，**嘴里说出来**，再点发送。系统只给这一层，不一次倒完。

4. 母亲做对或说出感觉（“眼熟”“这是小石爱吃的”），女儿在本子上记一笔。两边都确认，颜色才上去，下一段才开。

**提示只能一层一层给，和训练机制对齐：**

女儿还有叙事活：问错方向（以为小石是失散亲戚）、打电话、把年份排进时间线。这些会改下一句对白，**改不了母亲这关的正确答案。** 也就是：益智对错在母亲手上；故事走向在女儿手上。





# **3\. 母女是谁**

# **母亲：刘洪梅，小名小岩 **

- 姓**刘**，名**洪梅**。身份证、户口本、工牌、结婚证上都写「刘洪梅」。

- 「洪」是娘家那一辈的字辈，不是姓。同辈里女孩跟花：刘洪梅、刘洪兰、刘洪菊、刘洪芳；男孩如刘洪强、刘洪平。亲戚一开口，一串名字差一个字。

- 娘家刘姓的人多，厂里也多，同事懒得叫全名，都喊她**洪梅**。婆家叫她嫂子。下一辈叫梅姨。女儿叫老妈。

- 她嫌这名字，不是嫌难听，是嫌它像排座位：梅兰菊芳，少一个也有人补。

**小岩从哪来**

她小时候在姥姥家待过。村口河边捡岩石，摆窗台。姥爷随口一句：“这丫头不像花，风一吹就倒。像块小岩头，有自己的地方。”姥姥从此叫她小岩。只有这两个人这么叫。姥姥姥爷一走，再没人叫了。

后来别人叫她：小刘、洪梅、刘师傅、嫂子、知夏他妈、奶奶。小岩从家里的话里没了。

**她这个人**

能干，家里的事她说了算。不爱承认要人帮。爱用做饭管人。年轻时爱唱歌，没唱成。对女儿严，少说“我爱你”，问“吃饭了没有”。病了以后最烦别人当场纠错。名字会忘，口味、手势、愿不愿意戴那只发卡，还在。

特 别好客，只要有客人来了非常热情招待 无论熟不熟

# **女儿：张知夏 **

随父姓张。在外地上班。父亲去世，加上母亲明显不对，才回来收拾老屋，商量把母亲接到自己那边。

她一直以为妈妈就是：会做饭、管得宽、承担了太多的家庭责任、用“吃饭了吗”代替亲近、娘家婆家都找她办事的那个女人。

她不知道：母亲烦「洪梅」这两个字；爱吃辣；年轻时想唱歌；想过离开这个地方；成为妈妈以前，希望有人叫她小岩。

所以这局里真正要重新认识母亲的人，是女儿。

# **4\. 故事悬念**

开场不要开成“亲戚排队喊头衔”。更日常的是：

丧事刚过。屋里人来人往，电话不停。

有人喊二姐，有人喊梅姨，有人喊嫂子，有人喊刘师傅。

母亲有时应，有时没反应。女儿在本子上记谁来过，已经记混了。

收拾到抽屉、衣箱、录音机旁，四样东西不要一次摊在桌上，是分开翻到的：

1. 一张名字写在背面的10岁儿童黑白照片（夹在旧证件里，或压在镜子后）

2. 一盒没贴标签的磁带（录音机旁边，带已经有点粘）

3. 一本改得很乱的菜谱（灶台抽屉）

4. 一块背面浅浅刻了「小岩」的河石（不是摆件，是压着几张票据的镇纸）

母亲盯着照片说：“我要找到她。”

女儿：“她是谁？”

母亲：“忘了。”

**表面要找的： **照片里的女人是谁？

**其实在找的： **刘洪梅成为妻子、母亲以前，是什么样的人？

**最后问的： **名字和记忆往下掉的时候，一个人还能怎么回答“我是谁”？

女儿开局会猜错：这块岩石、这个小岩，大概是哪个失散的亲戚。

**两人分工**

母亲：点脸、说名字、拖人站位，过一会儿再叫。这是益智关。

女儿：通讯录、照片背面铅笔字、旧请柬。发现「人人都叫洪梅、没人叫小岩」写进调查本。母亲卡住，女儿按层读提示，不把名字标在母亲选项上。

**检验啥**

**玩完发现**

母亲叫不出那张年轻女人照片上的名字，却说：“她不喜欢这个名字。”女儿翻过河石背面看见「小岩」，当成某个没见过的亲戚的小名。人人都记得刘洪梅，没人接得上小岩。

**理论支撑**

早期 AD 的叫不出名字，常常是提取失败，不是完全不认识这张脸；所以要先自由命名，再给关系/首音提示，最后才再认，不能把四选一叫对写成命名改善。[Hodges, Salmon \& Butters, 1992, ](https://doi.org/10.1016/0028-3932(92)90104-T)[*Neuropsychologia*](https://doi.org/10.1016/0028-3932(92)90104-T)。脸–名–关系要用无错误学习和消退提示来教，反复猜错会把错的也学进去。[Clare, Wilson, Breen \& Hodges, 1999, ](https://doi.org/10.1080/13554799908404063)[*Neurocase*](https://doi.org/10.1080/13554799908404063)。过一会儿再叫一遍，对应间隔提取：成功拉长间隔，失败退回上一档，适合记具体人名，不声称改善整体记忆。[Creighton, van der Ploeg \& O’Connor, 2013, ](https://doi.org/10.1017/S1041610213001233)[*Int Psychogeriatr*](https://doi.org/10.1017/S1041610213001233)。

# **6\. 最后表达什么**

不是医学上“找回正确身份”，是三层可以同时存在的叫法：

给队友的收束句：

「刘洪梅」是户口本和亲戚记住她的方式。

「妈妈」是女儿认识她的方式。

「小岩」是她曾经认识自己的方式。

这些名字会糊，她仍能靠今天的选择，当一个具体的人。

色彩规则也按这个执行：

- 只核实了事实 → 轮廓清楚一点，还是灰的

# 8、美术设定关键词

# 画面风格解析

这是俄罗斯绘本《Когда бабушка и дедушка были маленькими》封面插画

1. **艺术风格**：复古纪实绘本插画，版画质感，手绘钢笔线稿\+平涂淡彩，带有老档案怀旧气质，偏向纪实文学绘本，不是卡通，偏成熟向图画书。

2. **线条**：钢笔勾线，线条松弛质朴，手部刻画写实，突出皮肤皱纹、苍老肌理；轮廓不完全锐利，带手绘速写感。

3. **色彩**：低饱和做旧色调，米白泛黄纸张底色，土黄、灰蓝、赭石棕、灰紫，色彩柔和褪色感，复刻旧相片、老书信的年代质感，少高饱和亮色。

4. **构图元素**：特写苍老的手，旧黑白照片、泛黄手写信件、信封、干枯植物、旧票据、细绳，大量老物件堆叠，回忆向叙事；俯视平面构图，物件平铺。

5. **氛围**：怀旧、追忆往事，沉静温柔，岁月感，家族记忆，旧时光档案感。
