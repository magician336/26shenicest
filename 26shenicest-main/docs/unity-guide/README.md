## 前置条件

- **引擎**：Tuanjie Engine 1.6.12（Unity 2022.3.61t13），安装路径 `E:\Software\Tuanjie\Hub\Editor\2022.3.61t13\`
- **项目路径**：`DoNotForgetMe/New Tuanjie Project/`
- **代码框架**：100% 就绪，70 个 C# 脚本已实现全部游戏逻辑
- **缺失项**：美术/音频/视频素材、DialogueSequence 资产、场景资产接线

## 快速开始（5 分钟跑通）

```
1. 用 Tuanjie Engine 打开项目
2. 等待编译完成（Console 无红色报错）
3. 菜单栏 → Tools > 3C Setup > Create Basic Scene
4. 按 ▶ Play
5. A/D 移动，F 交互，Tab 切换角色
```

## 游戏全景

```
MainMenu → Intro(过场) → LivingRoom(客厅探索)
                              │ F键进厨房
                              ▼
                          Kitchen(做饭小游戏)
                              │ 两道菜完成+照片收集
                              ▼
                         Courtyard(八卦小游戏)
                              │ 八卦完成+照片收集
                              ▼
                    LivingRoom(相册小游戏 → GameEnded)
```

**三个小游戏**：
1. **做饭**（链式两道菜：番茄炒蛋→凉拌黄瓜）— 母亲选食材，女儿加调料
2. **八卦**（桌面拖拽配对）— 母亲听故事配对物品，女儿认照片
3. **相册**（贴纸+姓名tag）— 双人同屏合作完成全家福

## 关键概念

| 概念 | 说明 |
|------|------|
| **Host / Client** | 代码层角色：Host=女儿（家属端），Client=母亲（患者端） |
| **GameplayIntent** | 玩家操作意图，由 Client 发送给 Host 处理 |
| **GameplaySnapshot** | Host 广播的游戏状态快照，双端同步 |
| **ScriptableObject 配置** | 所有小游戏参数通过 .asset 文件配置，数据驱动 |
| **代码生成 UI** | 所有游戏 UI 由代码动态创建，无需 Prefab，便于程序迭代 |
