# 07 · 对白系统配置

## 7.1 概述

对白系统用于在游戏阶段间插入电影感字幕对话。当前代码框架完整（`DialogueController` + `DialogueSequence` + `DialogueTrigger`），但 **DialogueSequence 资产尚未创建**。

## 7.2 对白系统架构

```
DialogueSequence.asset (数据)
    ↓ 被 Coordinator.dialogueConfigs 引用
DialogueController (UI 渲染)
    ↓ 监听 StateChanged
    ↓ phase == Dialogue && dialogue.IsActive 时渲染
    ↓ Host 点击全屏透明区域推进台词
DialogueTrigger (场景交互)
    ↓ F 键交互 → StartDialogue intent
```

### 对白触发方式

| 方式 | 说明 | 配置位置 |
|------|------|----------|
| **场景交互** | F 键触发 `DialogueTrigger` | 场景中的 DialogueTrigger 对象 |
| **自动播放** | 场景加载后自动播放 | Coordinator.openingDialogueId |
| **小游戏后链式** | 小游戏完成+照片收集后触发 | RecipeConfig/BaguaStoryConfig 的 nextDialogueId |
| **对白链式** | 一段对白播完自动接下一段 | DialogueSequence.nextDialogueId |

## 7.3 DialogueSequence 字段详解

通过 `Create > Data > Dialogue > Dialogue Sequence` 创建资产：

| 字段 | 类型 | 说明 |
|------|------|------|
| **Sequence Id** | string | 唯一标识（如 `opening_monologue`） |
| **Entries** | DialogueEntry[] | 台词数组 |
| **Cinematic Mode** | bool | true=电影模式（上下黑框）；false=底部字幕条 |
| **Next Mini Game Id** | string | 播完后自动启动的小游戏 ID |
| **Next Dialogue Id** | string | 播完后自动接续的对白 ID |

### DialogueEntry 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| **Speaker** | string | 说话人名字 |
| **Text** | string (TextArea) | 台词内容 |
| **Is Internal** | bool | true=内心独白（灰色显示"XX（内心）"） |
| **Audio Clip** | AudioClip | 可选配音音频 |

## 7.4 创建对白资产

### 方法 A：使用文本导入器（推荐）

1. 创建文本文件，格式为 `【角色名】台词`：

```
【知夏内心】这是哪里？这双手……不是我的。

【屋外声音】洪梅！别看书了，快来做饭！

【知夏内心】他们为什么叫我洪梅？难道这是妈妈小时候住过的地方？
```

2. 保存为 `.txt` 文件（UTF-8 编码）
3. 菜单栏 → **Tools > Dialogue > Import from Text**
4. 选择 txt 文件
5. 自动生成 `Assets/_Project/Dialogue/<文件名>.asset`

**解析规则**：
- `【角色名内心】` → speaker="角色名", isInternal=true
- 无 `【】` 的行 → 续行拼接到上一条台词
- 空行 → 分隔条目
- 导入后 audioClip 留空，需在 Inspector 手动挂接

### 方法 B：手动创建

1. 在 `Assets/_Project/Dialogue/` 右键 → **Create > Data > Dialogue > Dialogue Sequence**
2. 重命名（如 `OpeningMonologue.asset`）
3. 在 Inspector 中填写 `Sequence Id` 和 `Entries`

## 7.5 需要创建的对白序列

根据设计稿，以下对白序列是规划中的（可根据实际需求调整）：

### 7.5.1 开场对白（opening_monologue）

对应设计稿场景一内容：

```
【洪梅内心】小岩……小岩去哪儿了……
【知夏】妈，你说谁？
【洪梅】找不到了。
【知夏】谁找不到了？
【洪梅】小岩。
【知夏】小岩是谁？
【洪梅】忘了。
【知夏内心】没关系。我们一起找。
```

- `Sequence Id`: `opening_monologue`
- `Cinematic Mode`: true
- `Next Mini Game Id`: （空，进入探索）

### 7.5.2 做饭后对白（可选）

在 RecipeConfig 的 `Next Dialogue Id` 中填入对白 ID，完成做饭后会自动播放。

### 7.5.3 八卦后对白（可选）

在 BaguaStoryConfig 的 `Next Dialogue Id` 中填入对白 ID。

## 7.6 Coordinator 接线

对白资产创建后，需要接线到 `SessionGameplayCoordinator`：

1. 在 Hierarchy 中选中 `SessionGameplayCoordinator`
2. Inspector 中找到 `Dialogue Configs` 数组
3. 设置 `Size` 为对白资产数量
4. 将每个 `.asset` 拖入对应的 `Element`

### 开场对白接线

1. 在 Coordinator 的 `Opening Dialogue Id` 字段填入 `opening_monologue`
2. 场景加载后（且无存档、无照片收集记录时）自动播放

> **条件**：`openingDialogueId` 仅在 `collectedPhotoIds.Count == 0` 且 `State.dialogue.IsActive == false` 时触发。跨场景切换不会重复触发。

## 7.7 DialogueTrigger（场景交互）

如需在场景中放置可交互的对白触发器：

1. 在场景中创建空 GameObject
2. 添加 `DialogueTrigger` 组件
3. 设置 Layer = `Interactable` (10)
4. 添加 `BoxCollider2D`（isTrigger=true）
5. 添加 `SpriteRenderer`（可选，用于可视化）
6. 在 Inspector 中配置 `DialogueSequence` 引用

> `Scene3CSetup` 当前**不自动创建** DialogueTrigger。如需场景中的对白触发器，需手动添加。

## 7.8 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 对白不播放 | Coordinator.dialogueConfigs 未接线 | 将 .asset 拖入数组 |
| 开场对白不触发 | openingDialogueId 为空 | 填入 `opening_monologue` |
| 对白卡住不推进 | 只有 Host 能推进对白 | 按 Tab 切换到 Host 角色，点击屏幕 |
| 中文显示方块 | 字体问题 | 导入手写中文字体（见第 03 篇） |
