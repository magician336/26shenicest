# 09 · 网络配置与调试模式

## 9.1 两种网络模式

| 模式 | 宏定义 | 说明 | 当前状态 |
|------|--------|------|----------|
| **LocalDebug** | `FUSION_PRESENT` 未定义 | 单进程双端调试，Tab 切换角色 | ✅ 当前使用 |
| **Fusion** | `FUSION_PRESENT` 已定义 | Photon Fusion 在线联机 | ❌ 未启用 |

## 9.2 LocalDebug 模式（当前）

### 9.2.1 工作原理

```
LocalDebugService (替代 FusionSessionService)
  ↓ StartHost() → 设 Role=Host
  ↓ LocalGameplayBridge (替代 FusionGameplayBridge)
  ↓ Coordinator.debugSingleProcess = true → 绕过 Host 权限检查
  ↓ Tab 键 → 切换 Role (Host ↔ Client)
```

- 单进程运行，无需网络连接
- 所有 Intent 直接在本地处理
- `debugSingleProcess=true` 允许 Client 发送的 Intent 被直接处理（正常模式下只有 Host 能处理）

### 9.2.2 操作方式

1. 打开 `Game.unity`（或任意游戏场景）
2. 按 **▶ Play**
3. 默认角色为 **Host**（女儿端）
4. 按 **Tab** 切换到 **Client**（母亲端）
5. 再按 **Tab** 切回 Host

### 9.2.3 调试技巧

| 操作 | 效果 |
|------|------|
| Tab | 切换角色（Host ↔ Client） |
| A / D 或 ← / → | 移动玩家（仅 Host 可移动） |
| F | 交互（触发器、小游戏入口） |
| Console 窗口 | 查看日志（`[PlayerInput]`、`[Coordinator]` 等） |

### 9.2.4 从 MainMenu 启动

1. 打开 `MainMenu.unity`
2. 按 **▶ Play**
3. 点击 **创建** 按钮 → 生成房间码
4. `LocalDebugService` 检测不在游戏场景 → 加载 `Game.unity`
5. 进入游戏后同上操作

### 9.2.5 重置进度

菜单栏 → **Tools > 3C Setup > Clear Host Save**

删除 `HostSaveService` 存档 JSON，下次启动时从初始状态开始。

## 9.3 启用 Fusion 联机模式

### 9.3.1 前置条件

- Photon Fusion SDK 已导入（✅ 项目中 `Assets/Photon/Fusion/` 已存在）
- Photon App ID 已配置（✅ `PhotonAppSettings.asset` 中 AppIdFusion = `ecb11ee8-...`）
- FixedRegion = `asia`（✅ 已配置，新加坡节点，中国大陆延迟最低）

### 9.3.2 启用步骤

1. 菜单栏 → **Edit → Project Settings → Player → Other Settings**
2. 在 **Scripting Define Symbols** 中添加 `FUSION_PRESENT`
3. 等待重新编译
4. 编译完成后，运行 `Tools > 3C Setup > Create Basic Scene` 重新生成场景
   - 有 `FUSION_PRESENT` 宏时，`Scene3CSetup` 会：
     - 给 Player 添加 `NetworkObject` + `NetworkTransform`
     - 给 Coordinator 添加 `NetworkObject` + `FusionGameplayBridge`
     - `debugSingleProcess` 保持 false
   - 不再添加 `LocalGameplayBridge`

### 9.3.3 编译后变化

| 组件 | LocalDebug | Fusion |
|------|-----------|--------|
| SessionService | LocalDebugService | FusionSessionService |
| GameplayBridge | LocalGameplayBridge | FusionGameplayBridge |
| debugSingleProcess | true | false |
| Player 网络 | 无 | NetworkObject + NetworkTransform |
| Coordinator 网络 | 无 | NetworkObject |
| 角色切换 | Tab 键 | 由 Fusion Runner 角色决定 |

### 9.3.4 Fusion 联机测试

1. 在一台机器上打开项目 → MainMenu → **创建** → 获得6位房间码
2. 在另一台机器上打开项目 → MainMenu → 输入房间码 → **加入**
3. 创建者为 Host（女儿端），加入者为 Client（母亲端）

### 9.3.5 已知问题

| 问题 | 说明 |
|------|------|
| `Fusion NetworkProjectConfig.fusion` 资产冲突 | 非致命错误，每次启动报错，**忽略** |
| `FusionGameplayBridge` 需要编译验证 | 定义 `FUSION_PRESENT` 后检查 Console 无 Error |
