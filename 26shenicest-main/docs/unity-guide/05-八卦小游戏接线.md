# 05 · 八卦小游戏接线

## 5.1 概述

八卦小游戏是**双端非对称**小游戏：
- **母亲端(Client)**：听故事 → 拖拽物品配对到正确人物
- **女儿端(Host)**：照片认人 → 拖拽姓名标签到照片区域

所有配置在 `BaguaStoryConfig.asset` 中，`Scene3CSetup` 已自动创建默认数据。

## 5.4 素材接线步骤

### 步骤 1：接线人物立绘

1. 打开 `BaguaStoryConfig.asset`
2. 展开 `Entries` → `Element 0`
3. 将 `Assets/_Project/Art/Characters/liu_hongxiu_portrait.png` 的 Sprite 拖入 **Portrait** 字段
4. 将 `Assets/_Project/Audio/Story/audio_liu_hongxiu.wav` 拖入 **Story Audio** 字段
5. 重复 Element 1（刘洪菊）和 Element 2（刘洪斌）

### 步骤 2：接线物品图标

1. 展开 `Item Placements` → `Element 0`
2. 将 `Assets/_Project/Art/Items/item_key.png` 的 Sprite 拖入 **Sprite** 字段
3. 对 Element 1-7 重复操作，拖入对应物品图标

### 步骤 3：接线老照片

1. 将 `Assets/_Project/Art/Photos/bagua_old_family_photo.png` 的 Sprite 拖入 **Old Family Photo** 字段

### 步骤 4：验证

- 所有 ⚠️ 标记的字段变为已赋值状态
- 保存场景（Ctrl+S）

## 5.5 场景引用接线

### DoorListeningTrigger

1. 在 Hierarchy 中选中 `DoorListeningTrigger`（棕色方块, x=-6）
2. Inspector 中检查：
   - `Bagua Config Id` = `bagua_old_photo`
   - `Dialogue Audio Source` = 子物体 `DialogueAudio` 的 AudioSource

### SessionGameplayCoordinator

1. 选中 `SessionGameplayCoordinator`
2. 检查 `Bagua Configs` 数组：
   - `Element 0` = `BaguaStoryConfig.asset`

### MiniGameManager

1. 选中 `MiniGameManager`
2. 检查 `Bagua Configs` 数组（同上）

## 5.6 游戏流程

```
1. 玩家走到 DoorListeningTrigger (棕色方块, x=-6) 按 F
2. 母亲端(Client)：
   → 看到3个人物卡 + 8个散落物品
   → 点击人物卡上的声音按钮 → 播放故事音频（或字幕替代）
   → 听完后人物卡的虚线区域激活
   → 拖拽正确物品到对应人物的虚线区域
   → 正确：物品吸附填入 + 弹跳动画
   → 错误：物品返回原位 + 抖动动画
3. 3个物品全部配对正确 → 自动切换到女儿端
4. 女儿端(Host)：
   → 看到旧家庭照片 + 3个姓名标签
   → 拖拽姓名标签到照片上的正确区域
5. 全部正确 → 获得照片 bagua_old_family_photo
6. Host 收集 → 预览 → 关闭 → 自动转场回客厅
```

## 5.7 字幕机制

当 `Story Audio` 字段为空时，系统自动降级为字幕模式：
- 字幕内容 = `Subtitle` 字段文本
- 显示时长 = 字符数 ÷ 5 + 1 秒
- 在底部弹出，自动消失
- **有音频时字幕不显示**（音频优先）
