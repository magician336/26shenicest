# 02 · 场景生成与编辑器工具

## 2.1 编辑器工具总览

项目提供 3 个编辑器菜单工具，位于 `Tools` 菜单下：

| 菜单路径 | 功能 | 使用时机 |
|----------|------|----------|
| `Tools > 3C Setup > Create Basic Scene` | 一键生成 Game 场景 + 全部配置资产 + 引用接线 | 首次搭建 / 场景过期重生成 |
| `Tools > 3C Setup > Update Recipe Assets` | 更新菜谱资产并回写场景引用 | 修改菜谱后 |
| `Tools > 3C Setup > Clear Host Save` | 删除 Host 存档 JSON | 测试需要重置进度时 |
| `Tools > 3C Setup > Create Main Menu` | 生成主菜单场景 | 需要主菜单时 |
| `Tools > Dialogue > Import from Text` | 从文本文件导入对白 | 创建对白资产时（见第 07 篇） |

## 2.2 生成 Game 场景（核心步骤）

### 操作步骤

1. 打开 Tuanjie Editor
2. 确保当前没有打开其他场景（或新建空场景）
3. 菜单栏 → **Tools > 3C Setup > Create Basic Scene**
4. 等待执行完成（Console 会输出日志）
5. 场景自动保存到 `Assets/_Project/Scenes/Game.unity`

### 生成的场景对象层级

```
Game.unity
├── Ground                    ← 地面平台（灰色方块, Layer=Ground）
├── Platform1                 ← 右侧高台
├── Platform2                 ← 左侧高台
├── LeftWall / RightWall      ← 边界墙壁
├── Player                    ← 玩家（蓝色方块, Layer=Player）
│   ├── SpriteRenderer
│   ├── Rigidbody2D (gravityScale=3)
│   ├── BoxCollider2D
│   ├── PlayerController
│   ├── MovementController
│   ├── HealthController
│   ├── InteractionController
│   └── PlayerInputHandler
├── Main Camera               ← 正交相机 (orthographicSize=5)
│   └── RoomCameraController (follow=Player)
├── EventSystem               ← UI 事件系统
├── GameManager               ← [DefaultExecutionOrder(-100)] 单例
├── SessionGameplayCoordinator ← Host 权威状态机
│   ├── recipes[0] = TomatoEggRecipe.asset
│   ├── recipes[1] = CucumberSaladRecipe.asset
│   ├── baguaConfigs[0] = BaguaStoryConfig.asset
│   ├── albumConfigs[0] = AlbumConfig.asset
│   ├── debugSingleProcess = true
│   └── LocalGameplayBridge (无 FUSION_PRESENT 宏时)
├── MiniGameManager           ← 小游戏 UI 管理器
│   ├── recipes[0] = TomatoEggRecipe.asset
│   ├── recipes[1] = CucumberSaladRecipe.asset
│   ├── baguaConfigs[0] = BaguaStoryConfig.asset
│   └── albumConfigs[0] = AlbumConfig.asset
├── MiniGameTrigger           ← 做饭触发器 (x=3, 黄色方块)
├── DoorListeningTrigger      ← 八卦触发器 (x=-6, 棕色方块)
│   └── DialogueAudio (AudioSource, loop, volume=0)
├── AlbumTrigger               ← 相册触发器 (x=0, y=0.5, 棕色方块)
└── PlayerSpawn                ← 出生点 (0, 0, 0)
```

### 自动创建的配置资产

均位于 `Assets/_Project/Settings/`：

| 资产文件 | 类型 | 说明 |
|----------|------|------|
| `PlayerInputSettings.asset` | InputSettings | 输入参数 |
| `PlayerSettings.asset` | PlayerSettings | 移动速度等 |
| `MiniGameSettings.asset` | MiniGameSettings | 小游戏参数 |
| `TomatoEggRecipe.asset` | RecipeConfig | 番茄炒蛋菜谱 |
| `CucumberSaladRecipe.asset` | RecipeConfig | 凉拌黄瓜菜谱 |
| `BaguaStoryConfig.asset` | BaguaStoryConfig | 八卦3人物+8物件+3照片区 |
| `AlbumConfig.asset` | AlbumConfig | 相册6人物配置 |

### 自动配置的 Layer

```
Layer 8 = Ground
Layer 9 = Player
Layer 10 = Interactable
```

### 自动加入 Build Settings

`Game.unity` 会自动添加到 Build Settings 场景列表。

## 2.3 生成主菜单场景

1. 菜单栏 → **Tools > 3C Setup > Create Main Menu**
2. 场景保存到 `Assets/_Project/Scenes/MainMenu.unity`
3. 置于 Build Settings 首位

**生成内容**：

```
MainMenu.unity
├── Canvas (Screen Space Overlay)
│   ├── Background (Image)
│   ├── Title ("DO NOT FORGET ME")
│   ├── RoomCodeDisplay
│   ├── RoomCodeInput (InputField, 6位)
│   ├── CreateButton / JoinButton
│   ├── CancelButton / ContinueButton
│   ├── StatusText
│   └── MainMenuController
└── EventSystem
```

## 2.4 ⚠️ 重要警告

> **运行 `Create Basic Scene` 会覆盖现有 Game.unity！**
>
> 如果你已经在 Inspector 中手动接线了素材（Sprite、AudioClip 等），重跑此工具会**丢失所有手动接线**。
>
> **建议工作流**：
> 1. 先运行 `Create Basic Scene` 生成基础场景
> 2. 再手动接线素材（见第 03-07 篇）
> 3. **接线完成后不要重跑此工具**
> 4. 如需重跑，接线内容需重新操作

## 2.5 验证场景生成成功

1. Console 窗口应显示：
   ```
   [3C Setup] Scene created at Assets/_Project/Scenes/Game.unity
   [3C Setup] Controls: A/D or Left/Right = Move, F = Interact
   [3C Setup] Camera: Room-based — walks to screen edge to transition
   [3C Setup] MiniGame: Walk to the yellow box and press F to play
   ```
2. Hierarchy 窗口应显示上述对象层级
3. 按 **▶ Play** 测试：
   - Player 可用 A/D 或 ←/→ 移动
   - 走到黄色方块（MiniGameTrigger）按 F → 做饭小游戏启动
   - 按 **Tab** 切换角色（Host ↔ Client）
