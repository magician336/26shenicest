## 1. 项目概述

### 1.1 游戏简介

《小岩》是一款 **2D 横向点击交互的双人非对称叙事游戏**。两位玩家并排而坐，各持一块屏幕——母亲（Client）玩益智关卡，女儿（Host）持调查本推进剧情。两人必须开口说话才能推进流程，系统不自动同步答案。

**故事核心**：72 岁的刘洪梅有早期认知障碍。女儿张知夏翻出一张没写名字的年轻女人照片。母亲说"我要找到她"。两人一起做饭、听八卦、认亲戚，最终发现照片里的女人就是母亲自己——"小岩"是她成为"洪梅"之前的名字。

### 1.2 核心设计原则

| 原则 | 实现 |
|------|------|
| 母亲玩益智，女儿玩调查本 | 母亲(Client)操作食材拖拽/物品配对；女儿(Host)操作调味/提示/照片认人 |
| 女儿不能代点完成 | `CanRequesterPerform()` 在 Host 端校验角色权限 |
| 提示一层一层给 | `hintLevel` 递增，每次只解锁一层 |
| 不纠正母亲，故事也能走下去 | 选错只返回原位，不出现红叉，不扣分 |
| 母亲可主动要提示 | 母亲点"帮我看看"→女儿收到请求→女儿选择发送 |

### 1.3 三个小游戏

| 游戏 | 故事名 | 母亲端 | 女儿端 |
|------|--------|--------|--------|
| **做饭** | 她喜欢什么味道 | 找食材、拖入锅/碗 | 看菜谱改痕、选调料拖到菜上 |
| **听八卦** | 听力 | 桌面散落物件拖入人物卡虚线槽 | 等待→照片认人（拖姓名标签到照片区域） |
| **全家福认人** | 她叫什么名字 | 双端同屏共玩，贴纸+姓名tag两阶段串行 | 同左 |

### 1.4 五场景编排

| # | 场景 | 叙事对应 | 内容 |
|---|------|---------|------|
| 0 | **MainMenu** | 标题页 | 房间码创建/加入、继续游戏 |
| 1 | **Intro** | Scene0：前序过场 | 黑屏文字 + 内心OS + AIGC视频 + 时光回溯 |
| 2 | **LivingRoom** | Scene1：客厅书桌 | 醒来探索 → 走到门口进厨房；后期回到此处做相册小游戏 |
| 3 | **Kitchen** | Scene2：厨房 | 做饭小游戏（两道菜链式）→ 出门进庭院 |
| 4 | **Courtyard** | Scene3：庭院 | 八卦/偷听小游戏 → 完成后回到 LivingRoom 做相册 |

> 详细场景编排文档见 [docs/场景编排交付文档.md](场景编排交付文档.md)

### 3.2 Host 权威模式

所有游戏逻辑的权威判定只在 Host（女儿端）发生。Client（母亲端）的操作通过 `GameplayIntent` 发送给 Host 处理，Host 更新 `GameplaySnapshot` 后广播给双方。

```
母亲(Client)                              女儿(Host)
    │                                         │
    │  GameplayIntent (SelectIngredient)     │
    │ ───────────────────────────────────────→ │
    │                                         │  HandleHostIntent()
    │                                         │  → 校验角色权限
    │                                         │  → 更新 GameState
    │                                         │  → PublishStableState()
    │                                         │
    │  GameplaySnapshot (Clone)               │
    │ ←─────────────────────────────────────── │
    │                                         │
    │  StateChanged → Render(state)           │  StateChanged → Render(state)
```

### 3.3 GameplayIntent — 统一意图枚举

```csharp
public enum GameplayIntentType
{
    // --- 做饭小游戏 ---
    StartMiniGame,          // Host: 开始指定菜谱
    SelectIngredient,       // Client: 选择食材
    DropIngredient,         // Client: 拖入锅/碗
    SelectSeasoning,        // Host: 选择调料
    RequestHint,            // Client: 请求帮助
    ShowHint,               // Host: 发送下一层提示
    InterruptMiniGame,      // Host: 中断
    ResumeMiniGame,         // Host: 继续
    RestartMiniGame,        // Host: 重新开始
    FinishMiniGame,         // Host: 完成

    // --- 八卦小游戏 ---
    StartBaguaMiniGame,     // Host: 开始八卦
    MarkBaguaStoryHeard,    // Client: 标记已听故事
    MatchBaguaItem,         // Client: 配对人物-物品
    AssignBaguaPhotoName,   // Host: 照片认人

    // --- 照片收集 ---
    CollectMemoryPhoto,     // Host: 收集照片
    CloseMemoryPhotoPreview,// Host: 关闭照片预览

    // --- 全家福相册小游戏 ---
    StartAlbumMiniGame,     // Host: 开始相册
    PlaceAlbumSticker,      // 双端: 贴纸放入轮廓
    PlaceAlbumNameTag,      // 双端: 姓名标签放入名牌

    // --- 对白序列 ---
    StartDialogue,          // Host: 开始对白
    AdvanceDialogue,        // 双端: 推进下一句
    FinishDialogue          // Host: 结束对白
}
```

```csharp
public class GameplaySnapshot

    public string pendingPhotoId;       // 待收集照片
    public string previewPhotoId;        // 预览中照片
}
```

## 6. 场景编排与编辑器工具

### 6.1 五场景编排

```
MainMenu ──(StartHost/Client)──→ Intro ──(过场播完)──→ LivingRoom
                                                        │
                                          (走门口按F进厨房)
                                                        ▼
                                                     Kitchen
                                                        │
                                          (两道菜做完 + 照片收集)
                                                        ▼
                                                    Courtyard
                                                        │
                                          (八卦完成 + 照片收集)
                                                        ▼
                                              LivingRoom（回到客厅）
                                                        │
                                          (AlbumTrigger 按F → 相册小游戏)
                                                        │
                                              相册完成 → GameEnded
                                                        │
                                                   (Leave) → MainMenu
```

两类场景转场机制：

| 类型 | 触发方式 | 实现 |
|------|---------|------|
| **被动转场** | 小游戏完成 + 照片收集完毕后自动触发 | Coordinator 的 `_cookingChainCompleted` / `_baguaChainCompleted` → `CloseMemoryPhotoPreview` → `TransitionToScene` |
| **主动转场** | 玩家走到门口/灶台按 F | `SceneTransitionTrigger` → `SceneLoader.Load` |

### 6.2 跨场景持久化

| 对象 | 持久化方式 | 清理时机 |
|------|-----------|---------|
| `GameManager` | `DontDestroyOnLoad` | 不销毁（单例守卫） |
| `SessionGameplayCoordinator` | `DontDestroyOnLoad` | 回 MainMenu 时由 GameManager 销毁 |
| `MiniGameManager` | `DontDestroyOnLoad` | 回 MainMenu 时由 GameManager 销毁 |
| `MemoryAlbumController` | Coordinator 创建 + `DontDestroyOnLoad` | 随 Coordinator 销毁 |
| `DialogueController` | Coordinator 创建 + `DontDestroyOnLoad` | 随 Coordinator 销毁 |

### 6.3 当前 .unity 文件状态

```
Assets/_Project/Scenes/
├── MainMenu.unity    # 已存在
└── Game.unity        # 仍为唯一游戏场景（含所有玩法）
```

`SceneNames` 中 `LivingRoom` / `Kitchen` / `Courtyard` 当前都指向 `"Game"`，`SceneLoader` 的同场景守卫确保单场景调试不受影响。

### 6.4 编辑器菜单

| 菜单路径 | 功能 |
|----------|------|
| `Tools > 3C Setup > Create Basic Scene` | 一键创建 Game 场景（含所有对象、资产、Layer） |
| `Tools > 3C Setup > Update Recipe Assets` | 更新菜谱资产引用到场景（不重建场景） |
| `Tools > 3C Setup > Clear Host Save` | 清除 Host 本地存档 |

### 7.1 整体流程图

```
                                                    │

                                                    │
```

### 7.2 做饭小游戏详细流程

**第一道菜：番茄炒蛋**

1. Host 走到 MiniGameTrigger 按 F → `StartMiniGame("tomato_egg")`
2. **阶段 1 - 母亲选食材**：Client 拖拽番茄和鸡蛋到锅里
3. **阶段 2 - 女儿选调料**：Host 拖拽糖到菜上（菜谱改痕："洪强爱吃甜的，放点糖。"）
4. 完成 → 奖励 photo_hongqiang → 照片收集 → 自动开始第二道菜

**第二道菜：凉拌黄瓜**（链式触发）

1. Host 关闭照片预览 → `CloseMemoryPhotoPreview` → 检测 `_nextRecipeAfterPhoto`
2. 自动 `StartMiniGame("cucumber_salad")`
3. 正确调料：醋；菜谱改痕："洪芳喜欢酸一点多加点醋，但是不能吃辣！"
4. 完成 → 奖励 photo_hongfang → 照片收集 → `_cookingChainCompleted = true` → 自动转场到 Courtyard

### 7.3 八卦小游戏详细流程

1. Host 走到 DoorListeningTrigger 按 F → 音频渐变 → 3秒过渡 → 八卦小游戏
2. **阶段 1 - Client(母亲)**：点击人物听故事（音频/字幕）→ 拖桌面物件到已激活虚线槽
3. 3组全部配对 → 推进到 HostIdentifyPeople
4. **阶段 2 - Host(女儿)**：拖姓名标签到老照片投放区
5. 3个区域全部投放 → 完成 → 奖励 bagua_old_family_photo → 照片收集 → `_baguaChainCompleted = true` → 自动转场到 LivingRoom

### 7.4 全家福相册小游戏详细流程

1. 回到 LivingRoom 后，Host 走到 AlbumTrigger 按 F
2. AlbumTrigger 检查 `requiredPhotoIds`（3张照片）是否全部收集
3. 未集齐 → 显示"照片还不齐"提示
4. 集齐 → `StartAlbumMiniGame`
5. **阶段 1 - 贴纸**：双端均可拖拽 5 枚贴纸到对应轮廓框（characterId 校验）
6. 全部贴纸放入 → 推进到 PlaceNameTags
7. **阶段 2 - 姓名tag**：双端均可拖拽 5 个姓名标签到对应名牌区域
8. 全部姓名tag放入 → Complete → 出现"完成"按钮
9. 点击完成 → 全屏写实风全家福渐入 → 停留 → 淡入黑屏 → `FinishMiniGame` → GameEnded

> 小岩（刘洪梅）没有贴纸和姓名tag，轮廓始终空缺，引出终局。

### 7.5 照片收集与预览

```
小游戏完成
  → pendingPhotoId 设置 (移动锁定)
  → Host 点击"新照片·点击收集" → CollectMemoryPhoto
  → previewPhotoId 设置 (全屏预览)
  → Host 点击 × → CloseMemoryPhotoPreview
  → 检查链式触发:
     ├── _nextRecipeAfterPhoto → 自动开始下一道菜
     ├── _nextDialogueAfterPhoto → 自动开始下一段对白
     ├── _cookingChainCompleted → 转场到 Courtyard
     ├── _baguaChainCompleted → 转场到 LivingRoom
     └── 都没有 → 解锁移动，回到自由探索
```

### 7.6 中断/恢复/重启

Host 可随时点击"暂时离开"中断小游戏：

```
InterruptMiniGame → MiniGameInterrupted
  → 显示中断遮罩
  → Host 可选：
     ├── "继续" → ResumeMiniGame
     └── "重新开始" → RestartMiniGame
```
