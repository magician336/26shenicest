## 1. 概述

八卦小游戏是《小岩》的第二个小游戏模块。双人非对称合作：母亲（Client/患者端）听故事配对物品，女儿（Host/家属端）在老照片上认人。两阶段顺序推进，信息不对称，必须开口交流才能通关。

**核心设计原则**：
- 母亲做益智，女儿推进剧情
- 声音是唯一信息来源——不听故事无法配对
- 拖错只弹回，不惩罚
- 提示一层一层给

## 2. 领域术语

| 术语 | 代码层 | 说明 |
|------|--------|------|
| 女儿 | `SessionRole.Host` | 家属端。推进剧情、给提示、照片认人 |
| 母亲 | `SessionRole.Client` | 患者端。听故事、配对物品 |
| 听过 | `heardStoryIds` | 声音按钮播放完毕（音频或字幕），虚线区域激活 |
| 配对 | `matchedCharacterIds` | 正确物品拖入正确人物的虚线槽 |
| 投放 | `assignedPhotoZoneIds` | 女儿将姓名标签拖到照片区域 |
| ItemPlacement | — | 桌面物件统一配置（正确+干扰） |
| 虚线区域 | — | 人物卡上的物品放置槽，听过后才可拖入 |

## 3. 数据模型

### 3.1 BaguaStoryEntry — 人物条目

```csharp
[Serializable]
public class BaguaStoryEntry
{
    public string characterId;     // 如 "liu_hongxiu"
    public string displayName;     // 如 "刘洪秀"
    public Sprite portrait;        // 立绘 Sprite（可选，无则用色块）
    public AudioClip storyAudio;   // 故事音频（可选，无则用字幕）
    [TextArea] public string subtitle;  // 字幕文本
    public string age;            // 如 "18岁"
    public string title;           // 如 "大姐"
}
```

### 3.2 ItemPlacement — 桌面物件配置

```csharp
[Serializable]
public struct ItemPlacement
{
    public string itemId;           // 如 "key"
    public string displayName;      // 正确物品有名字（"铜钥匙"），干扰物留空
    public Sprite sprite;           // 物件图标（可选，无则用色块）
    public Vector2 anchoredPosition; // 桌面上固定坐标
    public bool isCorrect;          // 是否正确配对物
    public string characterId;      // isCorrect=true 时关联的人物ID
}
```

### 3.3 BaguaStoryConfig — 完整配置

```csharp
[CreateAssetMenu(menuName = "Data/MiniGame/Bagua Story Config")]
public class BaguaStoryConfig : ScriptableObject
{
    string miniGameId;               // "bagua_old_photo"
    string displayName;              // "八卦旧事"
    BaguaStoryEntry[] entries;       // 3个人物
    ItemPlacement[] itemPlacements;  // 8个物件（3正确+5干扰）
    Sprite oldFamilyPhoto;           // 老照片（Host认人阶段用）
    string[] rewardIds;             // 奖励ID
    PhotoZoneConfig[] photoZones;    // 照片投放区
}
```

### 3.4 BaguaGameState — 运行时状态

```csharp
[Serializable]
public class BaguaGameState
{
    GameplayPhase phase;             // Exploration | MiniGame | MiniGameInterrupted
    BaguaStep step;                 // ClientMatchItems | HostIdentifyPeople | Complete
    List<string> heardStoryIds;     // 已听完故事的人物ID
    List<string> matchedCharacterIds; // 已配对的人物ID
    List<string> assignedPhotoZoneIds; // 已投放的照片区域ID
    bool clientComplete;            // Client阶段完成
    bool hostComplete;              // Host阶段完成
    bool completed;                 // 全部完成
}
```

### 3.5 BaguaStep — 流程步骤

```
ClientMatchItems → HostIdentifyPeople → Complete
```

| 步骤 | 操作者 | 说明 |
|------|--------|------|
| `ClientMatchItems` | 母亲 | 听故事 + 物品配对 |
| `HostIdentifyPeople` | 女儿 | 老照片认人 |
| `Complete` | — | 全部完成，触发 FinishMiniGame |

## 4. 游戏流程

```
探索阶段
  │
  │ Host 走到 DoorListeningTrigger 按 F
  │ → 音频渐变（距离越近越清晰）
  │ → 3秒过渡文字 "你听见了他们的故事……"
  │
  ▼
ClientMatchItems（母亲端）
  │
  │ 1. 按声音按钮 → 播放音频/字幕 → 播完标记 heardStoryIds
  │ 2. 拖拽桌面物件到已激活的虚线区域
  │    → 正确：物品吸附填入 → matchedCharacterIds
  │    → 错误：弹回 + 抖动
  │ 3. 三组全部配对 → clientComplete → 自动推进
  │
  ▼
HostIdentifyPeople（女儿端）
  │
  │ 1. 母亲端显示等待文字
  │ 2. 女儿端显示老照片 + 姓名标签
  │ 3. 拖拽姓名标签到照片投放区
  │    → 正确：固定 → assignedPhotoZoneIds
  │    → 错误：弹回
  │ 4. 三个区域全部投放 → completed = true
  │
  ▼
完成
  │ → 1.4秒后自动 FinishMiniGame
  │ → 奖励入队 (bagua_old_family_photo)
  │ → 回到探索阶段，照片收集流程
  │
  ▼
照片收集（与做饭小游戏共用）
  │ → pendingPhotoId 设置 → 移动锁定
  │ → Host 点击收集 → 预览 → Host 关闭 → 解锁
```

### 5.2 人物卡结构

每张卡（520×200）从左到右：

| 区域 | 位置 | 内容 |
|------|------|------|
| 立绘 | 左1/3 | `entry.portrait` 或色块占位（130×160） |
| 姓名 | 中上 | `entry.displayName`（28号字） |
| 年龄·排行 | 中下 | `age + " · " + title`（20号字，暗色） |
| 声音按钮 | 中下 | 红色圆形60×60，内含"听"字。已听过后变绿 |
| 虚线槽 | 右侧 | 120×120，未听过灰色半透明，听过后金色高亮 |

### 5.3 物件状态

| 状态 | 表现 |
|------|------|
| 未配对（桌面） | 可拖拽色块，正确物品显示名称，干扰物无文字 |
| 拖入正确 | 虚线框消失 → 物品图缩放吸附（1.4→1.0，0.25秒）→ 不可再拖 |
| 拖入错误 | 弹回原位 + 左右抖动6帧 |
| 拖入未激活的卡 | 弹回原位 + 抖动（虚线区域未解锁） |

### 5.4 声音按钮交互

```
点击声音按钮:
  → 停止当前播放（打断不算听过）
  → 有音频 (storyAudio != null):
      播放音频，不显示字幕
      自然播完 → MarkBaguaStoryHeard → 虚线区域激活
  → 无音频 (storyAudio == null):
      底部弹出字幕条，文字 = subtitle
      时长 = subtitle.Length / 5 + 1 秒
      倒计时结束 → 字幕条消失 → MarkBaguaStoryHeard → 虚线区域激活
  → 可重复按（母亲忘了可以再听）
```

### 5.5 等待界面

配对完成后（`step == HostIdentifyPeople`）：
- 保持三张卡配对完成态（物品已填入）
- 底部显示"配对完成，等待女儿认人…"
- 无任何按钮（不可中断）

## 7. 交互逻辑详解

### 7.1 Intent 清单

| Intent | 操作者 | 触发场景 |
|--------|--------|----------|
| `StartBaguaMiniGame` | Host | DoorListeningTrigger 过渡完成 |
| `MarkBaguaStoryHeard` | Client | 声音按钮播放完毕 |
| `MatchBaguaItem` | Client | 物品拖入虚线区域 |
| `AssignBaguaPhotoName` | Host | 姓名标签拖入照片区域 |
| `InterruptMiniGame` | Host | 点"暂时离开" |
| `ResumeMiniGame` | Host | 中断后点"继续" |
| `RestartMiniGame` | Host | 中断后点"重新开始" |
| `FinishMiniGame` | Host | 自动触发（完成后1.4秒） |

### 7.2 配对校验流程

```
Client 拖拽物品 → OnEndDrag
  → 查找鼠标位置下的人物卡虚线槽 (FindCardDropZoneAt)
    → 未找到 → ReturnToOrigin
    → 找到但虚线未激活 (未听过故事) → ReturnToOrigin + Shake
    → 找到且已激活:
        → coordinator.Request(MatchBaguaItem, itemId, characterId)
        → BaguaSessionLogic.MatchItem:
            → _config.IsCorrectMatch(characterId, itemId)
                → 正确: matchedCharacterIds.Add → 检查是否全部完成
                → 错误: 返回 feedback="wrong_match" → ReturnToOrigin + Shake
```

### 7.3 中断/恢复

```
InterruptMiniGame
  → BaguaSessionLogic.Interrupt → phase = MiniGameInterrupted
  → MiniGameManager 显示中断遮罩:
      Host: [继续] [重新开始]
      Client: "等待女儿选择继续或重新开始"

ResumeMiniGame → phase = MiniGame → 恢复原状态
RestartMiniGame → BaguaSessionLogic.Restart → state.Reset → 重新开始
```

### 7.4 完成与奖励

```
全部投放完成 → completed = true → step = Complete
  → MiniGameManager 检测到 completed → 1.4秒后 FinishMiniGame
  → coordinator.FinishMiniGame:
      → phase = Exploration
      → QueueRewards(rewardIds) → pendingPhotoId = "bagua_old_family_photo"
      → 移动锁定，等待 Host 收集照片
```

## 11. 扩展指南

### 11.1 新增一组八卦故事

1. 创建 `BaguaStoryConfig` 资产（`Create > Data > MiniGame > Bagua Story Config`）
2. 配置 `entries`（人物信息）
3. 配置 `itemPlacements`（3正确 + N干扰，每个含坐标）
4. 配置 `photoZones`（照片投放区坐标和尺寸）
5. 设置 `rewardIds`
6. 在 `SessionGameplayCoordinator.baguaConfigs` 和 `MiniGameManager.baguaConfigs` 数组中添加引用
7. 场景中添加对应的 `DoorListeningTrigger`，设置 `baguaConfigId`

### 11.2 接入美术资源

| 资源 | 配置位置 | 当前 fallback |
|------|----------|--------------|
| 人物立绘 | `BaguaStoryEntry.portrait` | 色块 |
| 物件图标 | `ItemPlacement.sprite` | 色块 |
| 故事音频 | `BaguaStoryEntry.storyAudio` | 字幕条 |
| 老照片 | `BaguaStoryConfig.oldFamilyPhoto` | `[老照片]` 文字 |
| 桌面背景 | 代码中 `DesktopTray` 的 Image.color | 深棕色色块 |

### 11.3 调整物件位置

在 Inspector 中直接修改 `BaguaStoryConfig.asset` → `itemPlacements` 数组的 `anchoredPosition` 值。坐标基于桌面中心（0, 60），正值向右/上。

### 11.4 增减干扰物

修改 `itemPlacements` 数组长度，添加/删除 `isCorrect=false` 的条目。建议保持 3~5 个干扰物以平衡难度。

## 12. 已知限制

| 限制 | 说明 |
|------|------|
| 无美术资源 | 全部用色块 + 文字占位，功能完整但视觉为原型 |
| 无音频 | 声音按钮触发字幕条 fallback，无真实音频播放 |
| 无动画系统 | 物品吸附用手写 ScalePop 协程，非 Animator |
| 单进程调试 | FUSION_PRESENT 未定义，Tab 切角色测试双端 |
| 物件位置固定 | 不随机，每次布局相同 |
| 无返回按钮 | 母亲端不可中断，中断由 Host 控制 |
