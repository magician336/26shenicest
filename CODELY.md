- [2026-08-30 07:17:16] Unity VideoPlayer.Play() is async — `isPlaying` returns false on the first frame, so a `while (player.isPlaying)` loop exits immediately and the video never plays. Always call `player.Prepare()` first, wait for `player.isPrepared` (with a timeout), THEN call `player.Play()`, and use `while (elapsed < maxDuration) { if (!player.isPlaying) break; }` instead of `while (player.isPlaying && ...)`. **Why:** Both IntroCutsceneController and EndingController had this bug — videos were silently skipped. **How to apply:** All VideoPlayer usage in this project (and general Unity) must follow Prepare→wait→Play pattern.

- [2026-08-30 00:12:07] Tuanjie Engine uses base64-encoded GUIDs in .meta files (e.g. `guid: Dn5MtyP5V3PM18IOtjr5xnCUFpnLDFJH+iFs5M77aHxh8k732xO7cUA=`), but prefab YAML and .asset files reference sprites with standard 32-char hex GUIDs (e.g. `guid: 14c29d48562a9284a82c105bfedecc66`). The base64 GUID is NOT a simple encoding of the hex GUID — they use different internal representations and cannot be converted directly. To get the hex GUID of a Tuanjie asset, use AssetDatabase.FindAssets + GUIDToAssetPath via an Editor script (create a temp [InitializeOnLoad] script that writes GUIDs to a temp file, wait ~10s for compilation, then read it). Do NOT search .meta files for hex GUIDs — they only contain base64.
