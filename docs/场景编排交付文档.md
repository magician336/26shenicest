## 1. 设计目标

将游戏从单场景（`Game.unity`）拆分为 5 个场景，对应设计文档的叙事结构：

| # | 场景 | 叙事对应 | 内容 |
|---|------|---------|------|
| 0 | **MainMenu** | 标题页 | 房间码创建/加入、继续游戏 |
| 1 | **Intro** | Scene0：前序过场 | 黑屏文字 + 内心OS + AIGC视频 + 时光回溯 |
| 2 | **LivingRoom** | Scene1：客厅书桌 | 醒来探索 → 走到门口进厨房；后期回到此处做相册小游戏 |
| 3 | **Kitchen** | Scene2：厨房 | 做饭小游戏（两道菜链式）→ 做完听到屋外对话 → 出门进庭院 |
| 4 | **Courtyard** | Scene3：庭院 | 八卦/偷听小游戏 → 完成后回到 LivingRoom 做相册 |

### 流转图

```
MainMenu ──(StartHost/Client)──→ Intro ──(过场播完)──→ LivingRoom
                                                        │
                                          (走门口按F进厨房)
                                                        ▼
                                                     Kitchen
                                                        │
                                          (两道菜做完 + 照片收集)
                                                        ▼
                                                    Courtyard
                                                        │
                                          (八卦完成 + 照片收集)
                                                        ▼
                                              LivingRoom（回到客厅）
                                                        │
                                          (AlbumTrigger 按F → 相册小游戏)
                                                        │
                                              相册完成 → GameEnded
                                                        │
                                                   (Leave) → MainMenu
```

### 两类场景转场机制

| 类型 | 触发方式 | 实现 |
|------|---------|------|
| **被动转场** | 小游戏完成 + 照片收集完毕后自动触发 | Coordinator 的 `_cookingChainCompleted` / `_baguaChainCompleted` 标志 → `CloseMemoryPhotoPreview` → `TransitionToScene` |
| **主动转场** | 玩家走到门口/灶台按 F | `SceneTransitionTrigger` (IInteractable) → `SceneLoader.Load` |

#### `Cutscene/IntroCutsceneController.cs`

开场过场控制器，Awake 自动启动，流程：

1. **黑屏逐句内心独白** — 7 句文字渐入渐出，每句停留 3 秒
2. **AIGC 视频** — 可选 VideoClip，留空则跳过
3. **时光回溯闪白** — 暖白色全屏渐入渐出
4. **淡入黑屏并转场** — 加载 `SceneNames.LivingRoom`

```csharp
[SerializeField] private string[] monologueLines = new string[]
{

    "有人喊二姐，有人喊梅姨，有人喊嫂子，有人喊刘师傅。",
    "母亲有时应，有时没反应。",
    "她攥着一张残缺、模糊的旧全家福。",
    "「小岩……」",
    "「小岩去哪儿了……」",
    "没关系。我们一起找。"
};
```

所有节奏参数（渐入时长、停留时长、渐出时长、行间间隔）均可 Inspector 配置。

#### `Cutscene/SceneLoader.cs`

统一场景加载入口，封装同场景守卫和 Build Settings 存在性检查。

```csharp
public static class SceneLoader
{
    public static void Load(string sceneName)
    {
        if (SceneManager.GetActiveScene().name == sceneName) return;  // 同场景跳过
        if (!SceneNames.ExistsInBuildSettings(sceneName)) return;      // 不存在跳过
        SceneManager.LoadScene(sceneName);
    }
}
```

被 `IntroCutsceneController`、`SceneTransitionTrigger`、`SessionGameplayCoordinator.TransitionToScene` 三处共用。

#### `Interactables/SceneTransitionTrigger.cs`

场景切换触发器，实现 `IInteractable`。玩家按 F 交互后：

1. 检查前置条件（可选 `requiredPhotoIds`）
2. 检查 Coordinator 状态（不在 MiniGame 中）
3. 淡入黑屏（0.8s）
4. 黑屏停留（0.3s）
5. 调用 `SceneLoader.Load(targetScene)` 加载目标场景

```csharp
[SerializeField] private string targetScene = "Game";
[SerializeField] private string[] requiredPhotoIds;   // 留空=无前置
[SerializeField] private string lockedMessage = "还不能去那边。";
[SerializeField] private bool hostOnly = true;
```

**用途**：
- LivingRoom 的房门 → `targetScene = Kitchen`
- Kitchen 的灶台出口 → `targetScene = Courtyard`，`requiredPhotoIds = { "photo_hongqiang", "photo_hongfang" }`

#### 3.2.2 依赖重建：`sceneLoaded` 回调

```csharp
private void OnEnable()  { SceneManager.sceneLoaded += OnSceneLoaded; }
private void OnDisable() { SceneManager.sceneLoaded -= OnSceneLoaded; }

private void OnSceneLoaded(Scene scene, LoadSceneMode mode)
{
    if (scene.name == SceneNames.MainMenu) return;
    EnsureDependencies();
    InitializeSessionState();
}
```

`EnsureDependencies()` 确保 `MemoryAlbumController` 和 `DialogueController` 存在，创建的对象也加 `DontDestroyOnLoad`。

#### 3.2.3 双链完成标志

```csharp
private bool _cookingChainCompleted;   // 做饭两道菜全完成
private bool _baguaChainCompleted;     // 八卦完成
```

在 `FinishMiniGame()` 中设置：

```csharp
// 做饭分支
_cookingChainCompleted = string.IsNullOrEmpty(_nextRecipeAfterPhoto)
    && string.IsNullOrEmpty(_nextDialogueAfterPhoto);

// 八卦分支
_baguaChainCompleted = string.IsNullOrEmpty(_nextDialogueAfterPhoto);
```

#### 3.2.4 双链跨场景转场

`CloseMemoryPhotoPreview()` 中，照片收集完毕后按链完成标志触发转场：

```csharp
if (_cookingChainCompleted)
{
    _cookingChainCompleted = false;
    PublishStableState();
    TransitionToScene(SceneNames.Courtyard);   // 做饭完 → 庭院
    return;
}

if (_baguaChainCompleted)
{
    _baguaChainCompleted = false;
    PublishStableState();
    TransitionToScene(SceneNames.LivingRoom);   // 八卦完 → 回客厅做相册
    return;
}
```

`TransitionToScene` 委托给 `SceneLoader.Load` 统一处理守卫逻辑。

## 4. 跨场景数据流

### 4.1 持久化对象清单

| 对象 | 创建位置 | 持久化方式 | 清理时机 |
|------|---------|-----------|---------|
| `GameManager` | 首个游戏场景对象 | `DontDestroyOnLoad` | 不销毁（单例守卫） |
| `SessionGameplayCoordinator` | 首个游戏场景对象 | `DontDestroyOnLoad` | 回 MainMenu 时由 GameManager 销毁 |
| `MiniGameManager` | 首个游戏场景对象 | `DontDestroyOnLoad` | 回 MainMenu 时由 GameManager 销毁 |
| `MemoryAlbumController` | Coordinator 创建 | `DontDestroyOnLoad` | 随 Coordinator 一起销毁 |
| `DialogueController` | Coordinator 创建 | `DontDestroyOnLoad` | 随 Coordinator 一起销毁 |
| `NetworkRunner` (Fusion) | 代码创建 | `DontDestroyOnLoad` | `_runner.Shutdown()` 后 `Destroy` |

### 4.2 完整场景流转示例

```
[LivingRoom] 玩家走到门口按 F
  → SceneTransitionTrigger: targetScene=Kitchen
  → SceneLoader.Load("Kitchen") (当前="Game" → 跳过，单场景兼容)
  → [实际拆分后：加载 Kitchen 场景]

[Kitchen] 两道菜做完
  → FinishMiniGame: _cookingChainCompleted = true
  → CloseMemoryPhotoPreview: TransitionToScene(Courtyard)
  → SceneLoader.Load("Courtyard") (当前="Game" → 跳过)
  → [实际拆分后：加载 Courtyard 场景]

[Courtyard] 八卦完成
  → FinishMiniGame: _baguaChainCompleted = true
  → CloseMemoryPhotoPreview: TransitionToScene(LivingRoom)
  → SceneLoader.Load("LivingRoom") (当前="Game" → 跳过)
  → [实际拆分后：加载 LivingRoom 场景]

[LivingRoom] 玩家走到 AlbumTrigger 按 F
  → AlbumTrigger 检查照片齐全 → StartAlbumMiniGame
  → 相册完成 → GameEnded
```

### 4.3 防重复初始化守卫

`InitializeSessionState()` 中的开场对白条件：
- `collectedPhotoIds.Count == 0` — 跨场景切换后已有照片，不会重复触发
- `State.dialogue.IsActive` — 对白进行中不重复
- `HostSaveContext.Consume()` — 只在首次从 MainMenu 进入时返回存档

```

  ↓
LocalDebugService.StartHost() 检测已在游戏场景 → 不加载
```
