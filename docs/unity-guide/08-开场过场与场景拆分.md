# 08 · 开场过场与场景拆分

## 8.1 开场过场配置

### 8.1.1 IntroCutsceneController 概述

`IntroCutsceneController` 是开场过场控制器，挂载在 Intro 场景的 GameObject 上，`Awake` 自动启动。

**过场流程**：
```
黑屏 → 逐句内心独白文字（7句，每句停留3秒）
     → AIGC 视频（可选，最长15秒）
     → 时光回溯闪白（暖白色渐入渐出）
     → 淡入黑屏 → 加载 LivingRoom 场景
```

### 8.1.2 创建 Intro 场景

1. 菜单栏 → **File → New → Scene**（Empty Scene）
2. 在 Hierarchy 中创建空 GameObject，命名为 `IntroController`
3. 添加 `IntroCutsceneController` 组件
4. 保存场景到 `Assets/_Project/Scenes/Intro.unity`

### 8.1.3 IntroCutsceneController Inspector 字段

| 字段 | 默认值 | 说明 |
|------|--------|------|
| **Text Fade In Duration** | 1.5 | 文字渐入时长（秒） |
| **Text Hold Duration** | 3.0 | 文字停留时长（秒） |
| **Text Fade Out Duration** | 1.0 | 文字渐出时长（秒） |
| **Gap Between Lines** | 0.5 | 行间间隔（秒） |
| **Aigc Video Clip** | ⚠️ **需接线** | AIGC 视频 VideoClip（留空则跳过视频环节） |
| **Video Max Duration** | 15 | 视频最长播放时长（秒） |
| **Reversal Duration** | 2.0 | 时光回溯闪白时长（秒） |
| **Reversal Flash Color** | (0.9, 0.85, 0.7, 0) | 闪白颜色（暖白色） |
| **Final Fade Duration** | 1.5 | 最终黑屏淡入时长（秒） |
| **Monologue Lines** | 7句 | 内心独白文本（可在 Inspector 修改） |

### 8.1.4 默认独白文本

```
1. 丧事刚过。屋里人来人往，电话不停。
2. 有人喊二姐，有人喊梅姨，有人喊嫂子，有人喊刘师傅。
3. 母亲有时应，有时没反应。
4. 她攥着一张残缺、模糊的旧全家福。
5. 「小岩……」
6. 「小岩去哪儿了……」
7. 没关系。我们一起找。
```

### 8.1.5 接线 AIGC 视频

1. 将 `Assets/_Project/Video/intro_video.mp4` 拖入 **Aigc Video Clip** 字段
2. 如不接线，视频环节自动跳过（代码已处理 null 情况）

### 8.1.6 Intro 场景不需要的对象

Intro 场景**不需要**以下对象（`IntroCutsceneController` 自建 Canvas）：
- ❌ Coordinator / MiniGameManager（DontDestroyOnLoad 会从其他场景带过来）
- ❌ Player / Camera（过场无玩家操作）
- ❌ EventSystem（过场无 UI 交互）

## 8.2 场景拆分

### 8.2.1 当前状态

```
SceneNames.cs:
  LivingRoom = "Game"   ← 全指向同一个 Game.unity
  Kitchen    = "Game"
  Courtyard  = "Game"
```

单场景模式下，`SceneLoader` 的同场景守卫会跳过加载，所有区域在同一场景内运行。

### 8.2.2 拆分目标

```
SceneNames.cs (修改后):
  LivingRoom = "LivingRoom"
  Kitchen    = "Kitchen"
  Courtyard  = "Courtyard"
```

5 个场景文件：
```
Assets/_Project/Scenes/
├── MainMenu.unity       ← 已存在
├── Intro.unity          ← 新建（见 8.1）
├── LivingRoom.unity     ← 从 Game.unity 拆分
├── Kitchen.unity        ← 从 Game.unity 拆分
└── Courtyard.unity     ← 从 Game.unity 拆分
```

### 8.2.3 各场景内容清单

#### LivingRoom.unity

| 对象 | 必需 | 说明 |
|------|------|------|
| Player | ✅ | 玩家角色（首次创建，DontDestroyOnLoad 带到后续场景） |
| Main Camera | ✅ | 正交相机 + RoomCameraController |
| EventSystem | ✅ | UI 事件系统 |
| GameManager | ✅ | 全局管理器（首次创建） |
| SessionGameplayCoordinator | ✅ | 流程协调器（首次创建） |
| MiniGameManager | ✅ | 小游戏管理器（首次创建） |
| AlbumTrigger | ✅ | 相册触发器（x=0, y=0.5） |
| Ground/Walls | ✅ | 碰撞体 |
| SceneTransitionTrigger | ✅ | 房门 → targetScene=Kitchen |

#### Kitchen.unity

| 对象 | 必需 | 说明 |
|------|------|------|
| Player | ⚠️ | 如已有 DontDestroyOnLoad 则不需要；调试时需要 |
| Main Camera | ✅ | 相机 |
| EventSystem | ✅ | |
| MiniGameTrigger | ✅ | 做饭触发器（x=3, miniGameId=tomato_egg） |
| SceneTransitionTrigger | ✅ | 灶台出口 → targetScene=Courtyard, requiredPhotoIds=["photo_hongqiang","photo_hongfang"] |
| Ground/Walls | ✅ | 碰撞体 |

#### Courtyard.unity

| 对象 | 必需 | 说明 |
|------|------|------|
| Player | ⚠️ | 同上 |
| Main Camera | ✅ | 相机 |
| EventSystem | ✅ | |
| DoorListeningTrigger | ✅ | 八卦触发器（x=-6） |
| Ground/Walls | ✅ | 碰撞体 |

### 8.2.4 修改 SceneNames.cs

```csharp
public static class SceneNames
{
    public const string MainMenu   = "MainMenu";
    public const string Intro      = "Intro";
    public const string LivingRoom = "LivingRoom";   // 从 "Game" 改
    public const string Kitchen    = "Kitchen";       // 从 "Game" 改
    public const string Courtyard  = "Courtyard";      // 从 "Game" 改
    // ...
}
```

### 8.2.5 更新 Build Settings

1. 菜单栏 → **File → Build Settings**
2. 确保场景列表顺序如下：

| # | 场景 | 说明 |
|---|------|------|
| 0 | MainMenu.unity | 入口首位 |
| 1 | Intro.unity | 开场过场 |
| 2 | LivingRoom.unity | 客厅 |
| 3 | Kitchen.unity | 厨房 |
| 4 | Courtyard.unity | 庭院 |

3. **移除** `FusionIntroShared.unity`（Fusion demo，非项目场景）

### 8.2.6 SceneTransitionTrigger 配置

在拆分后的场景中添加场景切换触发器：

| 场景 | 触发器位置 | targetScene | requiredPhotoIds | hostOnly |
|------|-----------|-------------|-----------------|----------|
| LivingRoom | 房门附近 | Kitchen | （空） | true |
| Kitchen | 灶台/出口附近 | Courtyard | photo_hongqiang, photo_hongfang | true |

**SceneTransitionTrigger Inspector 字段**：

| 字段 | 说明 |
|------|------|
| **Target Scene** | 目标场景名（如 "Kitchen"） |
| **Required Photo Ids** | 前置照片 ID 数组（空=无前置条件） |
| **Locked Message** | 不满足条件时的提示文本 |
| **Host Only** | true=仅 Host 可交互 |

### 8.2.7 被动转场（自动）

以下转场由 Coordinator 在照片收集后自动触发，**无需手动配置**：

| 完成条件 | 转场目标 | 触发代码 |
|----------|---------|----------|
| 做饭两道菜全完成 + 照片收集 | Courtyard | `_cookingChainCompleted` → `TransitionToScene` |
| 八卦完成 + 照片收集 | LivingRoom | `_baguaChainCompleted` → `TransitionToScene` |

## 8.3 完整游戏流转图

```
MainMenu
  │ (创建/加入会话)
  ▼
Intro
  │ (过场播完)
  ▼
LivingRoom
  │ (走到门口按 F → SceneTransitionTrigger)
  ▼
Kitchen
  │ (两道菜完成 → 照片收集 → 自动转场)
  ▼
Courtyard
  │ (八卦完成 → 照片收集 → 自动转场)
  ▼
LivingRoom (回到客厅)
  │ (走到 AlbumTrigger 按 F → 相册小游戏)
  ▼
GameEnded (黑屏)
  │ (Leave → 回 MainMenu)
  ▼
MainMenu
```

## 8.4 不拆分也能玩

**单场景模式完全可用**。`SceneNames` 中三个场景名全指向 `"Game"`，`SceneLoader` 的同场景守卫会跳过加载。所有玩法在同一场景内运行，只是视觉上所有区域叠加在一起。

拆分的好处是**视觉清晰**和**性能优化**（每场景只加载需要的对象），但功能上不拆分也能跑通全流程。
