# 04 · 做饭小游戏接线

## 4.1 概述

做饭小游戏是**链式两道菜**：番茄炒蛋 → 凉拌黄瓜。每道菜由 `RecipeConfig` ScriptableObject 配置，`Scene3CSetup` 已自动创建默认数据和引用接线。

**当前状态**：代码和配置数据 100% 就绪，所有文本字段已填充。**缺失的是 Sprite 字段**（RecipeConfig 当前无 ingredientSprite 字段，做饭小游戏 UI 用文字标签渲染食材，这是架构设计决定，非缺陷）。

## 4.2 配置文件位置

| 资产 | 路径 |
|------|------|
| 番茄炒蛋 | `Assets/_Project/Settings/TomatoEggRecipe.asset` |
| 凉拌黄瓜 | `Assets/_Project/Settings/CucumberSaladRecipe.asset` |

## 4.4 场景引用接线

`Scene3CSetup` 已自动完成以下接线，**正常情况下无需手动操作**。但如果需要手动验证或修复：

### 4.4.1 SessionGameplayCoordinator

1. 在 Hierarchy 中选中 `SessionGameplayCoordinator`
2. Inspector 中检查 `Recipes` 数组：
   - `Element 0` = `TomatoEggRecipe` (拖入 TomatoEggRecipe.asset)
   - `Element 1` = `CucumberSaladRecipe` (拖入 CucumberSaladRecipe.asset)

### 4.4.2 MiniGameManager

1. 在 Hierarchy 中选中 `MiniGameManager`
2. Inspector 中检查 `Recipes` 数组（同上）

### 4.4.3 MiniGameTrigger

1. 在 Hierarchy 中选中 `MiniGameTrigger`（黄色方块, x=3）
2. Inspector 中检查：
   - `MiniGame Id` = `tomato_egg`
   - `Settings` = `MiniGameSettings.asset`

## 4.5 游戏流程

```
1. 玩家走到 MiniGameTrigger (黄色方块) 按 F
2. 母亲端(Client)：看到"请做番茄炒蛋"
   → 从番茄/鸡蛋/黄瓜/排骨中点选番茄和鸡蛋
   → 拖入锅中
3. 女儿端(Host)：看到菜谱改痕"洪强爱吃甜的，放点糖"
   → 从糖/盐中选择糖
   → 拖到菜上
4. 两端完成 → 获得照片 photo_hongqiang
5. Host 收集照片 → 预览 → 关闭预览
6. 自动启动第二道菜（凉拌黄瓜），重复 2-5
7. 第二道菜完成 → 获得照片 photo_hongfang
8. Host 收集 → 预览 → 关闭 → 自动转场到八卦场景
```

**Tab 键切换角色**：在 LocalDebug 模式下随时按 Tab 切换 Host/Client 视角。

## 4.6 修改菜谱（添加新菜）

如需添加第三道菜：

1. 在 `Assets/_Project/Settings/` 右键 → **Create > Data > MiniGame > Recipe Config**
2. 重命名为如 `SweetSourPorkRecipe.asset`
3. 在 Inspector 中填写所有字段
4. 在第二道菜的 `Next Recipe Id` 填入新菜谱 ID
5. 将新资产拖入 Coordinator 和 MiniGameManager 的 `Recipes` 数组

## 4.7 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 按 F 没反应 | MiniGameTrigger 未配置或坐标错误 | 检查 trigger 的 miniGameId 和 settings |
| 做完第一道菜没有第二道 | TomatoEggRecipe.nextRecipeId 为空 | 确认值为 `cucumber_salad` |
| 做完两道菜没转场 | Coordinator.recipes 数组只有1个 | 确认数组有2个元素且引用正确 |
| 母亲端看不到食材 | Tab 切换到 Client 视角查看 | 按 Tab 切换角色 |
