# 06 · 相册小游戏接线

## 6.1 概述

相册小游戏是**终局小游戏**，双人同屏合作。两阶段串行：贴纸投放 → 姓名标签 → 完成按钮 → 全屏全家福 → 黑屏终局。

**特殊设计**：6 个人物轮廓中，刘洪梅（小岩）没有贴纸，轮廓始终空缺，引出终局叙事。

## 6.4 素材接线步骤

### 步骤 1：接线贴纸 Sprite

1. 打开 `AlbumConfig.asset`
2. 展开 `Entries` → `Element 0`（刘洪秀）
3. 将 `Assets/_Project/Art/Characters/sticker_liu_hongxiu.png` 的 Sprite 拖入 **Sticker Sprite** 字段
4. 对 Element 2-5 重复操作（跳过 Element 1 小岩，`hasSticker=false`）

### 步骤 2：接线线索照片 Sprite

1. 在同一 Entry 中，将 `Assets/_Project/Art/Photos/clue_photo_liu_hongxiu.png` 的 Sprite 拖入 **Photo Sprite** 字段
2. 对 Element 2-5 重复操作（Element 1 小岩可留空）

### 步骤 3：接线写实全家福

1. 滚动到 AlbumConfig 顶部
2. 将 `Assets/_Project/Art/Photos/realistic_family_portrait.png` 的 Sprite 拖入 **Realistic Family Portrait** 字段

### 步骤 4：验证

- Element 1（刘洪梅）的 `Has Sticker` 必须为 **false**
- 其他 5 个 Entry 的 Sticker Sprite 和 Photo Sprite 均已赋值
- Realistic Family Portrait 已赋值

## 6.5 场景引用接线

### AlbumTrigger

1. 在 Hierarchy 中选中 `AlbumTrigger`（棕色方块, x=0, y=0.5）
2. Inspector 中检查：
   - `Album Config Id` = `album_family_portrait`

### SessionGameplayCoordinator

1. 选中 `SessionGameplayCoordinator`
2. 检查 `Album Configs` 数组：
   - `Element 0` = `AlbumConfig.asset`

### MiniGameManager

1. 选中 `MiniGameManager`
2. 检查 `Album Configs` 数组（同上）

## 6.6 前置条件（照片收集）

相册小游戏需要**3 张照片全部收集**才能进入：

| 照片 ID | 来源 |
|---------|------|
| `photo_hongqiang` | 做饭第一道菜（番茄炒蛋）奖励 |
| `photo_hongfang` | 做饭第二道菜（凉拌黄瓜）奖励 |
| `bagua_old_family_photo` | 八卦小游戏奖励 |

如果照片未集齐，走到 AlbumTrigger 按 F 会显示锁定提示（`lockedMessage`）。

**重置进度**：`Tools > 3C Setup > Clear Host Save`

## 6.7 游戏流程

```
1. （前置）完成做饭 + 八卦小游戏，收集全部3张照片
2. 走到 AlbumTrigger (棕色方块, x=0) 按 F
3. 双端看到相同的相册界面：
   Phase 1 - 贴纸阶段：
   → 5枚人物贴纸散落在底部
   → 6个剪影轮廓框（含小岩空缺位）
   → 拖拽贴纸到正确轮廓（characterId 匹配）
   → 5枚全部正确后进入 Phase 2

   Phase 2 - 姓名标签阶段：
   → 5个姓名标签出现
   → 拖拽到已填入贴纸的姓名区域
   → 5个全部正确后出现"完成"按钮

4. 点击完成按钮
5. 全屏展示写实全家福（CrossFadeAlpha 渐显）
6. 淡入黑屏 → 进入 GameEnded 阶段
```

## 6.8 线索查看器

- 相册界面左上角有"查看线索"按钮
- 点击后弹出全屏面板：照片 + 黄色便签（clueText）
- 双端均可查看
- **无提示系统**，只能通过口头沟通
