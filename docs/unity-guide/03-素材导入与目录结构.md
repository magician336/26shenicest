# 03 · 素材导入与目录结构

## 3.1 资产目录规划

在 `Assets/_Project/` 下创建以下目录：

```
Assets/_Project/
├── Art/
│   ├── Backgrounds/     ← 场景背景（4张, 1920×1080）
│   ├── Characters/      ← 角色立绘+贴纸（12张）
│   ├── Items/            ← 物品图标（18个, 256×256）
│   ├── Photos/           ← 奖励照片+全家福（7张）
│   ├── UI/               ← 木托盘、剪影轮廓等
│   └── Textures/         ← 旧照片纹理等
├── Audio/
│   ├── Story/            ← 八卦故事音频（3段）
│   ├── SFX/              ← 音效
│   └── BGM/              ← 背景音乐
├── Fonts/                ← 中文字体
├── Video/                ← AIGC 开场视频
└── Dialogue/             ← 对白文本文件（.txt）和资产（.asset）
```

## 3.3 导入设置

### 3.3.1 Sprite（2D 图片）

1. 选中导入的图片文件
2. Inspector 窗口设置：
   - **Texture Type**: Sprite (2D and UI)
   - **Sprite Mode**: Single（单张）或 Multiple（图集切片）
   - **Pixels Per Unit**: 100（默认）
   - **Filter Mode**: Bilinear（照片）或 Point（像素图标）
   - **Compression**: 根据需要选择质量

3. 透明背景图片确保 **Alpha Source**: Input Texture Alpha

### 3.3.2 AudioClip（音频）

1. 选中导入的音频文件
2. Inspector 窗口设置：
   - **Load Type**: Decompress On Load（短音效）或 Streaming（长音频）
   - **Compression Format**: PCM（WAV 无损）或 Vorbis（MP3 压缩）
   - **Sample Rate Setting**: Override → 44100 Hz

### 3.3.3 VideoClip（视频）

1. 选中导入的 MP4 文件
2. Inspector 窗口保持默认设置
3. 确保 **Codec** 选择正确（H.264）

### 3.3.4 Font（字体）

1. 将 TTF/OTF 文件放入 `Assets/_Project/Fonts/`
2. 字体会自动被 Unity 识别为 Font 资产
3. 后续在代码中替换 `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")` 为 `Resources.Load<Font>("Fonts/你的字体名")`

## 3.4 字体替换（全局）

当前所有 UI 代码使用 `Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf")`，可能导致中文显示异常。

**需要替换的脚本**（共 7 个）：

| 脚本 | 路径 | 替换位置 |
|------|------|----------|
| `CookingMiniGame.cs` | MiniGame/Cooking/ | `GetDefaultFont()` 方法 |
| `BaguaMiniGameView.cs` | MiniGame/Bagua/ | `GetDefaultFont()` 方法 |
| `AlbumMiniGameView.cs` | MiniGame/Album/ | `GetDefaultFont()` 方法 |
| `MiniGameManager.cs` | MiniGame/ | `GetDefaultFont()` 方法 |
| `MemoryAlbumController.cs` | UI/ | `GetDefaultFont()` 方法 |
| `IntroCutsceneController.cs` | Cutscene/ | `GetDefaultFont()` 方法 |
| `DialogueController.cs` | Dialogue/ | `CreateSubtitleTexts()` 内 |

**替换方法**：

方案 A（推荐）— 创建 `FontManager` 静态类：

```csharp
public static class FontManager
{
    private static Font _cached;
    public static Font Get()
    {
        if (_cached == null)
            _cached = Resources.Load<Font>("Fonts/YourFontName");
        return _cached ?? Resources.GetBuiltinResource<Font>("LegacyRuntime.ttf");
    }
}
```

方案 B — 在每个脚本中手动替换 `Resources.Load<Font>("Fonts/YourFontName")`。

> **注意**：字体文件需放在 `Assets/_Project/Resources/Fonts/` 目录下才能用 `Resources.Load` 加载。如果放在 `Assets/_Project/Fonts/`，需改用 `Resources.Load<Font>("Fonts/YourFontName")` 并确保路径在某个 `Resources` 文件夹下。
