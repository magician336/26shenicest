## 10.10 常见问题速查

| 症状 | 可能原因 | 解决方案 |
|------|---------|----------|
| Play 后黑屏 | 场景无 Camera 或 Coordinator | 运行 Create Basic Scene |
| 按 F 无反应 | 不在触发器范围内 / 角色不对 | 检查 Tab 当前角色 |
| 做饭后没第二道菜 | nextRecipeId 为空 | 检查 TomatoEggRecipe.asset |
| 八卦物品不可拖 | 未听故事 | 先点声音按钮听完故事 |
| 相册进不去 | 照片不足 | 检查 collectedPhotoIds |
| 中文显示方块 | 字体问题 | 导入中文字体（见 03 篇） |
| 玩家卡住不动 | 移动被锁定 | 检查 Console `[PlayerInput] 移动被锁定` |
| Console 报缺引用 | .asset 未接线 | 检查 Coordinator/MiniGameManager 数组 |
