# 01 · 环境准备与项目配置

## 1.1 安装 Tuanjie Engine

1. 下载 **Tuanjie Hub** 并安装 **Tuanjie Engine 1.6.12**（对应 Unity 2022.3.61t13）
2. 默认安装路径：`E:\Software\Tuanjie\Hub\Editor\2022.3.61t13\Editor\Tuanjie.exe`
3. 安装时勾选模块：
   - ✅ Build Support - Windows
   - ✅ Documentation

> **注意**：如果已有 Unity Hub，Tuanjie Hub 是独立安装，不冲突。

## 1.2 打开项目

1. 启动 Tuanjie Hub
2. 点击 **Open → Add project from disk**
3. 选择路径：`DoNotForgetMe/New Tuanjie Project/`
4. 首次打开会编译，预计 2-5 分钟

### 1.2.1 已知启动报错（可忽略）

| 报错 | 原因 | 处理 |
|------|------|------|
| `Fusion NetworkProjectConfig.fusion asset conflict` | Photon Fusion SDK 预置资产冲突 | **忽略**，不影响运行 |
| `Scene file is corrupted` | Game.unity 场景过期 | 运行 `Tools > 3C Setup > Create Basic Scene` 重新生成（见第 02 篇） |

### 1.2.2 编译验证

打开后检查 Console 窗口：

- ✅ **无红色 Error** = 编译通过
- ⚠️ **黄色 Warning** = 可忽略（Fusion SDK 相关）
- ❌ **有红色 Error** = 检查是否误删了脚本文件

> **批量模式编译验证**（不开编辑器 GUI）：
> ```powershell
> & "E:\Software\Tuanjie\Hub\Editor\2022.3.61t13\Editor\Tuanjie.exe" `
>   -batchmode -nographics `
>   -projectPath "D:\code_warehouse\Projects\hackathon\DoNotForgetMe\New Tuanjie Project" `
>   -logFile "D:\code_warehouse\Projects\hackathon\compile.log" `
>   -quit
> ```
> **注意**：必须先关闭编辑器 GUI，否则报 "another Tuanjie instance is running"。

## 1.4 Layer 配置

项目使用 3 个自定义 Layer，`Scene3CSetup` 会自动创建。如需手动确认：

1. 菜单栏 → **Edit → Project Settings → Tags and Layers**
2. 确认以下 Layer：

| Layer 编号 | 名称 | 用途 |
|-----------|------|------|
| 8 | Ground | 地面、墙壁（玩家碰撞） |
| 9 | Player | 玩家对象 |
| 10 | Interactable | 可交互物体（触发器、门等） |

> 如果 Layer 为空，运行 `Tools > 3C Setup > Create Basic Scene` 会自动填充。

## 1.5 FUSION_PRESENT 宏状态

当前项目 **未定义** `FUSION_PRESENT` 宏，因此：

- ✅ `LocalDebugService` + `LocalGameplayBridge` 激活（单进程调试）
- ❌ `FusionSessionService` + `FusionGameplayBridge` 不编译
- ✅ `SessionGameplayCoordinator.debugSingleProcess = true`（绕过 Host 权限检查）

**启用 Fusion 的方法**（暂不需要，见 [09-网络配置与调试模式](09-网络配置与调试模式.md)）：

```
Edit → Project Settings → Player → Other Settings → Scripting Define Symbols
添加 FUSION_PRESENT
```
