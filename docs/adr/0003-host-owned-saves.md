# 0003: 存档由 Host 独占并作为继续游戏入口

## Status

accepted

## 决策

跨会话进度仅保存到 Host 的存档。Host 从主菜单选择“继续游戏”加载存档后创建会话，Client 仅凭房间码加入该 Host 的当前进度，不持有或选择独立副本。

首版只提供一个 Host 本地自动存档槽位；新游戏经确认后覆盖该槽位，不提供多档案或云同步。

## 背景

游戏采用 Photon Fusion Host 模式，Host 已是探索、小游戏共享进度与奖励判定的权威。产品需要持久化进度并提供“继续游戏”，但两名参与者若各自持有可写副本，会出现解锁、收集物和中断小游戏进度的冲突与合并问题。

## Considered Options

- **双方各自存档并合并**：落选。需要冲突解决策略，且与 Host 权威相悖，不适合首版。
- **仅会话内保存**：落选。无法提供“继续游戏”。

## Consequences

- Client 加入前不加载或修改游戏进度；进入会话后接收 Host 的进度快照。
- 持久化读写集中在 Host，首版无需跨设备存档同步或双写冲突处理。
- 主菜单可据该槽位是否存在显示“继续游戏”；新游戏会覆盖原进度。
- Host 仅在小游戏子任务推进、奖励结算、退出小游戏、场景切换和正常结束会话等稳定节点自动存档，不在逐帧或拖拽中间状态写盘。
